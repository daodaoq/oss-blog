# 自主扩展：本地全文搜索增强（任务6）

> 选型：**本地全文索引 · 关键词高亮 · 无结果建议**（对应实验可选功能清单第 4 项）
> 仓库位置：`theme/assets/js/search.js`、`theme/assets/css/journal.css`（`.mz-search-*`）、
> `theme/default.hbs`（弹层结构）、以及由本扩展驱动的搜索按钮 `data-ghost-search`。
> 关联 Issue：#2 ｜ 关联 PR：feature 分支合并 PR ｜ 分支：`feature/custom-theme`（含主题与扩展改动）

## 1. 用户价值
个人博客的"搜得到"决定了内容能不能被再利用。Ghost 默认搜索要依赖第三方 CDN 的
sodo-search，且无法给出命中反馈；本扩展提供一个**不依赖外部 CDN、可离线、即时反馈**
的站内全文搜索：输入即搜、命中关键词高亮、无结果时给出建议而不是一片空白。

## 2. 为什么做在"主题/上层"，而不是改 Ghost 核心
- 搜索索引直接来自 Ghost 已公开的 **`/rss/`** 接口（上游能力），前端在主题层聚合与检索；
- 因此无需改动 Ghost core、无需自建服务端索引，跟随 Ghost 升级不受影响；
- 二次开发增量被限定在一个可独立替换的 `search.js` + 一段样式里，天然可回滚。

## 3. 非目标（明确不做）
- 不做服务端全文索引/排序（那是 Lucene/ES 级别，超出"上层扩展"边界，见思考题）
- 不改动 Ghost 的 posts 表结构、不加数据库字段
- 不索引受密码/会员私密文章
- 不实现聚合搜索（作者/标签页搜索暂不包含，只搜文章）

## 4. 界面入口与操作
- 所有页面右上/头部 **🔍 按钮**，或键盘 **`/`** / **`Ctrl+K`**（macOS `⌘K`）唤起
- 输入关键词即检索标题 + 摘要 + 标签；`Enter`/点击结果进入文章
- `Esc` / 点背景 / ✕ 关闭

## 5. 失败状态（都有明确 UI）
| 场景 | 表现 |
|---|---|
| 输入为空 | 不检索，无结果区空白 + 提示条 |
| 无命中 | "未找到与「xx」相关的文章" + "试试更短关键词" 建议 |
| RSS 拉取失败（如离线异常） | 索引为空，显示无结果空态，不抛错、不影响页面 |

## 6. 实现要点（技术说明）
- `search.js`：首次唤起时 `fetch('/rss/')` 建本地索引（标题/描述/标签），内存缓存；
  检索 = 小写 includes，命中标题与摘要时用 `<mark>` 高亮（先 HTML 转义再插标签，防注入）。
- 纯原生 JS、零依赖、零 CDN，满足离线演示要求。
- `default.hbs` 在 `ghost_foot` 前注入弹层与脚本；捕获阶段接管所有 `data-ghost-search`
  点击，避免触发外部 sodo 默认行为。
