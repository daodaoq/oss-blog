## Issue #1：基线选型与固定版本（任务1）

**标题**：实验01 基线：选择 Ghost 作为二次开发基线并固定版本 v6.62.0

**正文**（可直接粘贴）：

```markdown
## 背景
《开源软件与新技术》实验01：开源个人博客系统二次开发。要求基于成熟开源博客系统做受控二次开发，
交付本地可运行、可注册、可写作、可评论、可搜索的个人博客软件，禁止重写认证/数据库/编辑器等核心。

## 选型
- 候选 A：RealWorld 规范（API 规范，非可运行应用，需自建全部核心）
- 候选 B：TryGhost/Ghost（MIT，Node.js 完整博客产品）✅ 采用

理由：复用成熟核心，把二次开发边界限定在自定义主题 + Content API + 上层扩展，
2 学时内即可达成 MVP 主线，且可保留清晰 Git 证据区分上游/本人工作。

## 固定版本
- Ghost 6.62.0（runtime 内 package.json 锁定）
- Node v22.x / npm 10.x / SQLite（本地 ghost install local）

## 风险与对策
见 docs/requirements.md §5（网络慢、端口占用、主题兼容、数据误提交等）。

## 验收场景（详见 docs/requirements.md §4）
AS-1 管理员写作发布绑定标签；AS-2 两类账号；AS-3 会员评论(拒空评论)；
AS-4 搜索命中与无结果提示；AS-5 全站可用+移动端；AS-6 重启不丢数据+导出导入恢复。

## 负责人

```
