## Issue #1 · 基线选型与固定版本（任务1）
**标题**：实验01 基线：选择 Ghost 6.62.0 作为二次开发基线（Docker Compose 本地运行）

**正文**：与 `docs/requirements.md §3-§4` 一致——选型对比、固定版本、风险、6 条验收场景(AS-1…AS-6)。

```markdown
## 背景
《开源软件与新技术》实验01。基于成熟开源博客做受控二次开发，交付本地可运行、可注册、
可写作、可评论、可搜索的个人博客软件；禁止重写核心，禁止仅改样式冒充二次开发。

## 选型
RealWorld 规范(需自建全部核心) vs TryGhost/Ghost(MIT，Node 完整博客产品) —— 采用 Ghost。
理由：复用成熟核心，把开发边界限定在自定义主题 + Content API + 上层扩展，
2 学时内达成 MVP，且能保留 Git 证据区分上游/本人工作。

## 固定版本与运行
- Ghost 6.62.0（官方镜像），SQLite，本地邮件接收器 mail-sink
- 运行：docker compose up -d  → 前台 http://localhost:2368 后台 /ghost

## 风险与对策
国内网络/原生 Windows 不支持 → 见 docs/requirements.md §5

## 验收场景（详细见 docs/requirements.md §4）
AS-1 管理员写作发布绑定标签；AS-2 两类账号(管理员+会员)；AS-3 会员评论(拒空)；
AS-4 搜索命中+无结果提示；AS-5 全站+移动端；AS-6 重启不丢+导出导入恢复。

负责人：sjk
```

## Issue #2 · 自主扩展：本地全文搜索增强（任务6，勾选验收）
**标题**：自主扩展：站内全文搜索——关键词高亮 + 无结果建议（不改 Ghost 核心）

```markdown
## 用户价值
把已发布内容变成"可被找到"。博客内容越多越需要靠谱的站内搜索；
默认搜索依赖外网 CDN、反馈弱，本扩展要一个**离线可用、即时反馈、命中高亮**的搜索。

## 为什么在主题/上层做（不改核心）
索引源直接用 Ghost 公开 /rss/，前端在主题层聚合检索；
无 core 改动、无数据库改动，跟随 Ghost 升级不受影响。见 docs/extension-search.md。

## 非目标（不做）
- 不做服务端全文索引(ES/Lucene 级)；不改 posts 表结构；不索引私密/会员文章
- 不做作者/标签聚合搜索（本轮只搜文章）

## 界面入口
头部 🔍 按钮 或键盘 `/`、`Ctrl+K` → 弹出搜索框，输入即搜
无结果 → "未找到相关文章" + 建议；Esc/点背景/✕ 关闭

## 失败状态
空输入不检索；RSS 拉取失败显示空态不报错；无命中给友好建议。

## 验收条件
- [ ] 按钮 / `/` / Ctrl+K 可打开
- [ ] 搜"二次开发" ≥2 篇命中
- [ ] 命中词在结果里 <mark> 高亮
- [ ] 乱词显示"未找到…"提示，不报错
- [ ] 空输入不检索不报错
- [ ] 不加载外网 CDN 即可完成搜索（离线）
- [ ] 全部改动在 theme/ 内（git diff 边界清晰），未改 Ghost 核心

关联：基线 Issue #1 ｜ 实现代码 feature/custom-theme 分支 ｜ 合并 PR Closes #2
```
